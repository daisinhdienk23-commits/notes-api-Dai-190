2. Năm đặc tính điện toán đám mây theo NIST

Đặc tính NIST Thao tác đã thực hiện trong bài
On-demand Self-service
(Tự phục vụ theo nhu cầu)		 Tự tạo GitHub Codespace để có môi trường lập trình mà không cần nhờ nhà cung cấp cấu hình thủ công.
Broad Network Access
(Truy cập mạng rộng rãi)		 Mở cổng 3000 ở chế độ Public và sử dụng điện thoại truy cập API thông qua URL HTTPS.
Resource Pooling
(Gộp tài nguyên)		 Sử dụng CPU, RAM và hệ điều hành Linux được cung cấp bởi hạ tầng đám mây của GitHub Codespaces.
Rapid Elasticity
(Co giãn nhanh)		 Tạo và khởi chạy môi trường Codespace theo nhu cầu, có thể dừng khi không sử dụng.
Measured Service
(Dịch vụ được đo lường)		 Kiểm tra mức sử dụng tài nguyên và chi phí tại GitHub Billing → Usage.
